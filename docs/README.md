# ZYVORA documentation

**Pilot-ready software, not a certified medical product. Synthetic data only.**

ZYVORA is hospital software: patients, appointments, wards, theatre, laboratory, imaging, pharmacy and billing in one system, with an optional assistant that **drafts** and people who **decide**. These pages explain it in plain words. You do not need to be technical to read them, and the [glossary](GLOSSARY.md) explains every special term.

> **In one minute.** You can install a demo on your own computer with one command and try it with invented patients; nothing leaves your machine. ZYVORA is built and tested with made-up data only, and it is not certified for real clinical use. These pages say clearly what it does, and just as clearly what it does not.
