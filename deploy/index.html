Deploy

Run it your way.

The same two container images, a Rust API and a web front end, on a laptop, a VM or a Kubernetes cluster.

Docker Compose

The quickest route: API, web, PostgreSQL and an optional edge. Run in a FluxVM virtual machine and used for the browser test suite.

Helm chart

Network policies, a migration job and PostgreSQL through CloudNativePG.

k3s with Keycloak and Envoy

Keycloak (Haven packaging) for sign-in, Envoy Gateway as the TLS edge with a session check, and CloudNativePG for the database.

Try it

Install it on your Mac or Linux laptop.

One command starts the whole product on your own machine, with synthetic patients to look at. Apple Silicon, Intel and Linux (amd64 or arm64).

1. A container engine

Docker Desktop or OrbStack, or Podman. On a Mac with Homebrew: brew install podman podman-compose, then podman machine init and podman machine start. On Linux: your package manager's podman and podman-compose, or Docker with the compose plugin. You also need curl; add Node 20 or later if you want the sample data.

2. One command

Downloads the installer, checks its checksum, pulls the two images and starts everything. The first run takes a few minutes.

3. Sign in as a doctor

Open the address the installer prints (port 8443, this machine only), accept the browser's warning for the self-signed certificate, choose Continue with single sign-on, then pick Dr. Meera Rao. There is no password in demo mode.

curl -fsSL https://github.com/zyvorai/zyvor-zyvora-site/releases/latest/download/get.sh | sh -s -- up --demo --seed

On Windows

Windows runs it inside WSL 2 (Windows 10 version 2004 or later, or Windows 11). Run wsl --install -d Ubuntu once in an administrator PowerShell and restart, then use Docker Desktop with WSL integration switched on, or add -InstallPodman to the command and it sets up podman inside WSL for you. Not yet verified on a Windows PC: tell us what you see.

& ([scriptblock]::Create((irm https://github.com/zyvorai/zyvor-zyvora-site/releases/latest/download/get.ps1))) up --demo --seed

Check and remove

Run ~/.zyvora/app/deploy/install/install.sh test to check that everything answers. ~/.zyvora/app/deploy/install/install.sh uninstall removes the containers and their data.

Real sign-in

Replace --demo --seed with --with-demo-users to start Keycloak as well, with a generated admin password kept in ~/.zyvora/env. Details are in the release notes.

For evaluation with synthetic data only: no real patient data, and nothing here is a clinical or regulatory claim. The script is short and writes only under ~/.zyvora; read it first at the release page if you like.
