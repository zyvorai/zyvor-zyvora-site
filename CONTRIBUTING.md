# Contributing

Thank you for looking at ZYVORA. This repository is the **public website, installer and release notes**; the product source is private, and the website files here are generated from it. That shapes how you can help.

## What helps most

- **Feedback from the demo.** What worked, what confused you, what you wanted to see. If something failed, include the output of `~/.zyvora/zyvora test` and your computer type. Use the **Feedback** issue form, or email [sales@zyvor.dev](mailto:sales@zyvor.dev).
- **Reports that the installer or the site does not work.** Use the **Bug report** form and say which computer and which version.
- **Windows testers.** The Windows installer has not been verified on a real Windows PC. If you try it, please tell us what you see.
- **Security reports** go to [security@zyvor.dev](mailto:security@zyvor.dev), never into a public issue. See [SECURITY.md](SECURITY.md).

## Please never include

**Patient data or credentials.** Not in an issue, not in a screenshot, not in a log excerpt. ZYVORA is built and tested with synthetic data only.

## Pull requests

Pull requests are not accepted for the website files: they are regenerated from the product repository, and a hand edit here would be overwritten on the next publish. If you spot a mistake on the site or in these docs, open an issue and we will fix it at the source.
